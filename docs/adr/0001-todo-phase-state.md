# Todo 阶段状态与 Pi 适配器分离

Todo 阶段状态通过一个统一、同步、无副作用的状态转换模块提供；模块继续使用 `Phase[]` / `Item` 快照，返回新状态和结构化错误。Pi 工具、`/todo` 命令、会话持久化、HUD 和提醒保留在外部适配器中，以便通过一个稳定接缝测试状态不变量，同时保持现有用户行为不变。

## Considered Options

将状态转换、持久化和 HUD 继续放在 `oh-my-pi-todo.ts` 中会让 Pi 运行时依赖进入核心规则，并使工具与命令难以共享一个完整测试接口；为每个操作分别暴露函数会扩大调用者必须学习的接口，因此采用一个统一状态转换入口。
